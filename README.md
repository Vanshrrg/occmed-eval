# แบบประเมินอาชีวอนามัยและเวชกรรมสิ่งแวดล้อม

เว็บสำหรับทีมโรงพยาบาลใช้ประเมินร่วมกันจากหลายเครื่อง (แก้ไขพร้อมกันได้ เห็นข้อมูลอัปเดตทันที)

- **ส่วนที่ 1** ประเมินมาตรฐานการจัดบริการอาชีวอนามัยและเวชกรรมสิ่งแวดล้อม รพศ./รพท. (48 ข้อ)
  - ให้คะแนนตนเอง 0–3 ทุกข้อ ใส่ผู้รับผิดชอบ หมายเหตุ และลิงก์หลักฐาน Google Drive
  - คำนวณร้อยละรายองค์ประกอบ และระดับ (เริ่มต้นพัฒนา / ดี / ดีมาก / ดีเด่น) อัตโนมัติ
  - นับถอยหลังถึงวันประเมิน (ตั้งค่า `P1_DEADLINE` ใน `config.js`)
- **ส่วนที่ 2** ขึ้นทะเบียนคลินิก (แบบ ม25ว3-5): checklist เอกสาร ผู้รับผิดชอบ ลิงก์หลักฐาน และสถานะ ครบ/ไม่ครบ
- **สรุปผล**: ตารางคะแนน ตารางร้อยละการผ่านเกณฑ์ และรายการข้อที่ยังไม่ทำ

ข้อมูลเก็บใน Supabase (ฟรี) ส่วนไฟล์หลักฐานเก็บใน Google Drive ของหน่วยงาน (บันทึกเฉพาะลิงก์)

---

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)

### 1. สร้างฐานข้อมูล Supabase
1. สมัคร/เข้าสู่ระบบที่ https://supabase.com แล้วกด **New project** (แผน Free)
2. เมนู **SQL Editor** → **New query** → คัดลอกเนื้อหาไฟล์ `supabase/schema.sql` มาวาง → กด **Run**
3. เมนู **Authentication → Users → Add user → Create new user**
   ใส่อีเมลและรหัสผ่านของทีม (ใช้ร่วมกันทั้งทีม) และติ๊ก *Auto Confirm User*
4. เมนู **Authentication → Sign In / Providers**: ปิด **Allow new users to sign up** (ป้องกันคนนอกสมัครเอง)
5. เมนู **Project Settings → API** คัดลอก **Project URL** และ **anon public key**

### 2. ตั้งค่าเว็บ
แก้ไฟล์ `config.js`:
```js
SUPABASE_URL: 'https://xxxx.supabase.co',
SUPABASE_ANON_KEY: 'eyJ...',
HOSPITAL_NAME: 'โรงพยาบาล...',
P1_DEADLINE: '2027-06-01'   // ปี ค.ศ.-เดือน-วัน
```
> anon key เปิดเผยได้ ข้อมูลถูกป้องกันด้วยการเข้าสู่ระบบ + Row Level Security

### 3. เผยแพร่บน GitHub Pages
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลด/push ไฟล์ทั้งหมดในโฟลเดอร์นี้
2. **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main` / `(root)` → Save
3. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` ส่งให้ทีมใช้ได้เลย

> ถ้า repository เป็น public ใครก็เห็นหน้าเว็บ (แต่ไม่เห็นข้อมูลถ้าไม่มีรหัสผ่านทีม)

## การใช้งาน
- เข้าสู่ระบบด้วยอีเมล/รหัสผ่านทีม และใส่ **ชื่อของคุณ** (แสดงว่าใครแก้ไขล่าสุด กดที่ชื่อมุมขวาบนเพื่อเปลี่ยน)
- ทุกการแก้ไขบันทึกอัตโนมัติ จุดสีเขียวมุมขวาบน = บันทึก/เชื่อมต่อแล้ว, สีเหลือง = กำลังบันทึก, สีแดง = มีปัญหา
- **ลิงก์ Google Drive**: ในไฟล์/โฟลเดอร์ Drive กด *แชร์* → ตั้ง *ทุกคนในองค์กร* หรือ *ทุกคนที่มีลิงก์* (ผู้มีสิทธิ์อ่าน) → *คัดลอกลิงก์* แล้ววางในช่องลิงก์ของแต่ละข้อ
  แนะนำให้สร้างโฟลเดอร์ Drive กลางของทีม แยกโฟลเดอร์ย่อยตามข้อ
- ปุ่ม **พิมพ์** พิมพ์/บันทึกเป็น PDF หน้าที่เปิดอยู่
- ถ้ายังไม่ตั้งค่า Supabase เว็บจะอยู่ใน **โหมดทดลอง** (บันทึกในเบราว์เซอร์เครื่องนั้นเท่านั้น)
